# TrustChain Donation

A blockchain-based transparent donation platform that enables donors to track how their contributions are utilized.

## Key Features

- 💰 Transparent donation tracking
- 🔗 Blockchain-based transaction records
- 📊 Fund utilization tracking
- ✅ Milestone verification
- 🪪 Donor Passport
- 🔍 Public audit trail
- 🦊 MetaMask wallet integration

## Problem

Donors often cannot clearly see where their donated money goes after making a contribution.

## Solution

TrustChain creates a transparent flow where donations, milestones, verification records, and fund utilization can be publicly tracked.

## Technology

- React
- JavaScript
- Blockchain
- Polygon
- MetaMask
- Smart Contracts
- Web3
